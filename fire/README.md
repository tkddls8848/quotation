# FIRE 계산기

모아 둔 돈과 앞으로의 저축, 은퇴한 뒤에 쓸 돈을 넣으면 **언제 일을 그만둘 수
있는지** 셈한다. 전부 브라우저 안에서 돈다 — 넣은 숫자는 서버로 가지 않는다.

```text
fire/web/src/
  model.ts        계산. DOM 도 브라우저 API 도 쓰지 않는다
  model.test.ts   계산이 맞는지 대조 (26가지)
  view.ts         화면 — 입력 항목 정의에서 폼을 만들고 결과를 그린다
  fire.css        이 기능 전용 스타일
```

## 판정 방식

"25배를 모으면 끝"(4% 규칙)은 **참고선으로만** 보여 준다. 가능·불가 판정은 월
단위 모의 실험이 한다 — 은퇴 시점부터 기대 수명까지 매달 물가가 오른 만큼 더
쓰고, 남은 자산은 세후 수익률로 굴리고, 국민연금이 나오면 그만큼 덜 뽑는다.
그렇게 끝까지 자산이 남으면 "가능" 이다.

어림 대신 모의 실험을 쓰는 이유는 4% 규칙이 미국 주식·채권 60/40 을 30년 굴린
결과라서다. 한국의 예금·적금·채권 위주 자산, 물가, 15.4% 이자소득세, 65세부터
들어오는 국민연금은 그 전제와 다르다.

세금은 이자·배당 원천징수 15.4% 를 기본으로 보고, 한 해 금융소득이 2,000만원을
넘으면 초과분의 종합과세를 선택으로 반영한다. 국내 상장주식의 시세 차익은
소액주주 기준으로 비과세로 셈하므로, 해외 주식·ETF 라면 양도세 22% 만큼 상승률을
낮춰 넣어야 한다 (화면이 그 주의를 띄운다).

## 다른 기능과의 경계

- 다른 기능(`quotation/`, `converters/`)을 **부르지 않는다.** 반대도 마찬가지다.
- 셸(`web/`)이 `@fire` 별명으로 `web/src/view.ts` 의 `mountFire` 하나만 부른다.
  머리말·꼬리말·스타일까지 이 폴더가 갖는다.
- **기능 바깥에 공유 코드를 두지 않는다.** 다른 기능이 쓸 법한 것이라도 밖으로
  빼지 않고 여기 둔다. 공유는 이 폴더 안에서만 한다 — 밖에 둔 공유부는 거기
  생긴 문제 하나를 여러 기능의 장애로 번지게 한다 (결정 0012).

## 고칠 때

숫자가 틀리면 없느니만 못한 화면이라 계산을 화면에서 떼어 두었다. `model.ts` 를
고쳤으면 반드시 돌린다.

```bash
npm --prefix web test        # ../fire/web/src/model.test.ts 까지 함께 돈다
```
