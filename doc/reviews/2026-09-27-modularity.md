# 모듈 경계·탐색 비용·환경 파일 검토

범위: 2026-09-27 현재 작업 트리. 검토 시작 시 변경 파일이 없었다.
문서 변환기는 9월 24일 별도 저장소로 분리되어 이 검토 대상에 없다.
소스는 Git 파일 목록과 역할별 검색으로 조사했고 환경 변수의 실제 값은 출력하지 않았다.

| 판단 | 발견한 문제 | 반영한 수정 |
|---|---|---|
| 높음 | `.gitignore`에 `.env*`·`.dev.vars*` 차단이 없어 인증 파일을 실수로 커밋할 수 있었다 | Git 제외 규칙과 실제 파일 추적 여부 검사 추가 |
| 높음 | Vite 기본 설정이 `.env`를 읽고 `VITE_*`를 클라이언트에 노출할 수 있었다. 실제 유출이 발견된 것은 아니다 | `envDir: false`, `envPrefix: []`. 가짜 토큰을 프로세스에 넣어 노출되지 않음을 검사 |
| 중간 | 환경 파일이 인증정보 전용이라는 정책·검사가 없었다 | 루트만 허용하고 계정·토큰 키를 명시. 개발·빌드·테스트에서 위치·키 검사. 오류에 값 미포함 |
| 중간 | `writer/mod.rs` 824줄에 셀 서식·TOTAL·상세·꼬리말·워크북 조립이 함께 있었다 | `cells.rs`, `total.rs`, `detail.rs`, `footer.rs` 분리. 공개 API와 계산 규칙 유지 |
| 중간 | 정규식 import 검사에서 `new URL(..., import.meta.url)`·CommonJS 참조를 놓치고 주석을 코드로 오인할 수 있었다 | JS/TS는 TypeScript AST로 읽는다. 재내보내기·worker URL·require·절대 경로 검사와 우회 회귀 사례 추가 |

| 중간 | 작업 진입점이 여러 README와 역사 문서에 흩어져 대량 읽기를 유도했다 | 짧은 루트 `AGENTS.md`, writer 책임별 지도, 설정 위치 표 추가 |
| 낮음 | 다시 큰 파일이 생기는 것을 막을 검사가 없었다 | 운영 Rust/TS/JS/CSS 소스 500줄 검사 추가. 테스트·생성물·역사 문서는 제외 |

분리 후 `writer/mod.rs`는 182줄이다. 새 모듈은 `cells.rs` 169줄,
`total.rs` 149줄, `detail.rs` 271줄, `footer.rs` 71줄이다.

## 유지한 구조

`web/`은 빌드·배포 셸, `quotation/`은 기능 소유자다. Rust core가 계산 규칙을
소유하고 데스크톱·WASM·Python은 어댑터 역할을 한다. 이 경계는 유지했다.
분리한 함수는 writer 안에서만 `pub(super)`로 공유하며 외부 공개 API는 늘리지 않았다.

489줄의 `decorate.rs`, 464줄의 데스크톱 `ui.rs`, 411줄의 webapi `lib.rs`는
관찰 대상이지만 이번에는 줄 수만으로 나누지 않았다. 이미 역할과 진입점이
분명하고, 수십 개의 작은 파일로 쪼개면 오히려 탐색 비용이 늘어난다.
592줄의 과거 웹 계획서는 역사 기록으로 보존하고 기본 탐색 대상에서 제외했다.
lockfile·바이너리·생성물을 소스처럼 읽지 않도록 작업 지도에 명시했다.

## 환경 파일 판정

검토 범위에서 실제 `.env*`·`.dev.vars*`는 발견되지 않았다. 따라서 일반 설정이
이미 섞여 있다는 발견은 없으며, 값의 이동이나 삭제도 없었다.
새 검사기는 생성물·의존성·캐시를 제외한 실제 로컬 환경 파일도 검사한다.
인증 파일의 심볼릭 링크를 거부한다. Git 검사는 추적되는 비밀 파일을 별도로 막는다.

`DEPLOYMENT_VERSION`, `DESKTOP_REPO`, `LOCALAPPDATA`, 테스트 브라우저 경로는
정당한 프로세스 환경변수다. `.env` 전용 정책과 혼동해 제거하지 않았다.
자세한 위치·허용 키·한계는 [설정 안내](../guide/CONFIGURATION.md)에 있다.

## 검증 범위

기존 Rust core/webapi의 공개 fixture·워크북·수식 관련 회귀를 실행한다.
프런트엔드 테스트에는 환경 정책·실제 Vite 해석 결과·모듈 경계·파일 크기·
Git 환경 파일 추적 여부를 포함한다. TypeScript 검사와 Vite 빌드도 실행한다.
이 검토는 토큰 사용량의 정량 벤치마크나 전체 Git 이력의 비밀값 감사를 뜻하지 않는다.
큰 모듈의 분리와 탐색 지도는 읽을 범위를 줄이지만 모델별 절약 토큰을 측정하지 않았다.

실행 결과: Rust core/webapi 54개 테스트, 프런트엔드 33개 테스트가 통과했다.
`cargo fmt --all -- --check`, 해당 두 크레이트의 `cargo clippy --all-targets -- -D warnings`,
TypeScript 검사, Vite 프로덕션 빌드, `git diff --check`도 통과했다.
이번 변경에서 네이티브 GUI 조작이나 WASM 재빌드·브라우저 동일성 검증 전체는
다시 실행하지 않았다. 계산·워크북 회귀는 재구성된 Rust 소스로 실행했다.
