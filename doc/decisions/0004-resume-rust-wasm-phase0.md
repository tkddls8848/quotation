# 결정 0004 — Rust→WASM Phase 0의 폐기 결정을 철회한다

- 날짜: 2026-08-26
- 상태: **적용됨**
- 철회한 결정: [결정 0003](0003-reject-rust-wasm-core-after-phase0.md)

## 결론

Rust→WASM 전환 계획은 Phase 0 상태로 되돌린다. 결정 0003은 전환을 폐기하는
근거로 사용할 수 없다.

## 이유

결정 0003의 비교는 템플릿을 `umya-spreadsheet`와 openpyxl로 각각 열어 `C3` 한
셀만 바꾸고 저장한 파일끼리의 비교였다. 이 실험은 라이브러리별 OOXML 직렬화
차이를 찾는 데는 쓸 수 있지만, **같은 구성 XML을 변환한 Python 산출물과 Rust
산출물의 동등성 비교가 아니다.** 당시 Rust 구현은 XML을 읽거나 견적서 값을
쓰지 않았으므로 그 저장본을 “Rust 변환 결과”라고 부를 수 없다.

따라서 파일 크기·ZIP 부품 수·직렬화 차이만으로 계획을 폐기한 것은 부당했다.
계획의 실제 최종 관문은 Phase 4에서 독립 Rust 변환기가 같은 XML을 처리한
결과를 `xlsx_parity.py`와 셀 단위 골든 회귀에 통과시키는 것이다.

## 다음 검증

사용자가 제공한 `1180_64c_1024_800 4ea_10G 4ea_32G 2ea.xml`을 고정 입력으로
사용한다. 현행 Python 기준 파일과, 구현이 완료된 뒤의 독립 Rust 산출 파일을
나란히 제공한다. 그 전에는 Rust가 열어 저장한 round-trip 파일을 보존성 관문용
산출물로만 표시하며, 독립 변환 결과로 표시하지 않는다.
