# 결정 0020 — 사무 도구를 변환기 탭 안에 들인다

- 날짜: 2026-09-24
- 상태: **적용됨**
- 관련 결정: [결정 0012](0012-one-folder-per-feature.md),
  [결정 0018](0018-browser-only-converters.md)

## 결론

변환기 탭에 도구 **16개**를 더 들인다. 모두 브라우저 안에서 끝나고, 새 의존성은
QR 코드 하나(`qrcode-generator`, MIT)뿐이다.

| 갈래 | 도구 | 쓰는 것 |
|---|---|---|
| PDF | 워터마크·쪽번호, 서명·도장 넣기, 모아찍기·빈 쪽 빼기, 문서 정보 보기·지우기 | pdf-lib·pdfjs-dist (이미 있음) |
| 이미지·텍스트 | 이미지 형식·크기 바꾸기, 텍스트 비교, 글자 수 세기, 개인정보 가리기 | 캔버스·`encoding.ts` |
| 사무 계산 | 금액 한글 표기, 부가세 계산, 날짜·영업일 계산, 사업자·법인등록번호 검증 | 없음 (순수 계산) |
| 파일 | 표 합치기·나누기, 파일 이름 일괄 바꾸기, 파일 해시 확인, QR 코드 만들기 | SheetJS(워커)·fflate·`crypto.subtle`·qrcode-generator |

## 왜 새 기능 폴더가 아니라 `converters/` 인가

결정 0012 는 **기능마다 최상위 폴더 하나**를 둔다. 계산기 넷은 "변환" 이 아니라서
따로 둘 만도 하다. 그러지 않은 이유는 둘이다.

1. **쓰는 자리가 같다.** 견적서를 만들고 나면 금액을 한글로 적고, 부가세를 맞추고,
   PDF 로 뽑아 도장을 찍고, 대외비 워터마크를 넣는다. 이 흐름이 탭 두 개로 갈라지면
   쓰는 사람이 오간다.
2. **나눌 코드가 이 폴더 안에 있다.** PDF 도구는 `pdf.ts`·`pdf-render.ts`·
   `fonts.ts` 를, 텍스트 도구는 `encoding.ts` 를, 표 도구는 SheetJS 워커와 `zip.ts`
   를 쓴다. 폴더를 나누면 결정 0012 에 따라 이것들을 두 벌 들어야 한다.

계산기가 커져 변환기와 나눌 이유가 생기면 그때 `office/` 로 옮긴다. 계산기 넷은
DOM 없는 순수 모듈이라 옮기는 값이 작다.

## 스물다섯을 한 판에 두지 않는다

고르는 화면을 **갈래 다섯**(문서 형식 변환 · PDF · 이미지·텍스트 · 사무 계산 ·
파일)으로 묶었다. 기존 단추의 `data-choice` 는 그대로다.

새 도구는 **고를 때 가서** 코드를 받는다(`panel.ts` 의 동적 `import`). PDF 병합만
하러 온 사람이 QR·표 합치기 코드까지 받을 이유가 없다 — 견적서 탭이 변환기 코드를
받지 않는 것과 같은 규칙을 한 단계 더 안으로 내렸다.

화면 조각(상태 줄·내려받기 링크·끌어다 놓기)은 `kit.ts` 한 벌로 모았다. 도구
열여섯이 같은 몇 줄을 저마다 들면 한 군데만 고쳐지는 일이 생긴다.

## 새 의존성 하나

QR 부호화(리드-솔로몬·마스크 선택)는 손으로 짜면 수백 줄이고 틀리면 찍히지 않는
그림이 나온다. 검증된 것을 쓴다. `qrcode-generator` 는 의존성이 없고 MIT 이며,
QR 도구를 고를 때만 받는다. 라이선스 사본은 `web/public/licenses/` 에 있다.

기본 문자열 변환이 Latin-1 로 잘라 한글이 깨지므로 UTF-8 바이트로 바꿔 넣는다
(`qr.ts`).

## 무엇을 보장하지 않는가 — 화면에 적은 것

- **서명·도장 넣기는 전자서명이 아니다.** 그림을 얹을 뿐이라 누구나 떼어 쓸 수 있다.
- **개인정보 가리기는 모양으로 찾는다.** 이름·주소·자유 형식 번호는 놓친다. 보내기
  전에 사람이 봐야 한다.
- **사업자번호 검증은 검증 숫자만 본다.** 휴·폐업은 홈택스에서 확인해야 한다 — 번호를
  어디로도 보내지 않는다.
- **영업일 계산은 음력 공휴일·대체공휴일을 모른다.** 양력 고정 공휴일만 넣을 수 있고
  나머지는 직접 적는다.
- **부가세의 원 미만 처리는 거래처마다 다르다.** 버림이 기본이고 반올림·올림을 고른다.
- **빈 쪽 판별은 추정이다.** 후보를 보여 주고 사람이 고른 뒤에만 뺀다.

## 확인

도구마다 순수 계산을 떼어 단위 테스트로 고정했다(`npm --prefix web test`).
화면은 `converters/web/scripts/check-converters.mjs` 가 실제 Chromium 으로 열어 본다.
