# 전환 안내 — 기존 사용자용

2005년판 `견적서 자동화 프로그램` 에서 2026년판 `견적서 작성기` 로 넘어갈 때 알아야 할 것.

---

## 1. 무엇이 그대로인가

- **입력**: eConfig Export XML. 바꿀 것 없다.
- **출력 내용**: 기존 양식을 유지하며 상세 구성품, 수량, LP 가격을 옮긴다.
  날짜·크기·글꼴 등 일부 표현은 실행 환경과 템플릿에 따라 달라질 수 있다.
- **화면 구성과 조작 순서**: XML 선택 → 옵션 → 변환.
- **오류 문구**: `CFData을 찾을수 없습니다.`, `견적서 작성을 위한 Item을 찾을 수 없습니다.` 등 그대로다.

## 2. 무엇이 달라지는가

### 출력 확장자가 `.xlsx` 다
`.xls` → `.xlsx`. Excel 2007 이후 버전이면 그대로 열린다.
받는 쪽이 `.xls` 를 요구하면 Excel 에서 `다른 이름으로 저장 → Excel 97-2003 통합 문서` 를 쓰면 된다.

### 유지정비료를 채우지 않는다
구버전은 XML 의 `MaintenanceUnitListPrice` 를 H열(제안가/유지정비료)에, 기간을 I열에
넣었다. 이제 넣지 않는다. H열은 표 구조(테두리·배경·병합)만 유지된 **빈 칸**으로 나오므로
필요하면 손으로 적으면 된다.

### 견적서 번호와 담당자는 템플릿에서 고친다
`견적서_template_IBM.xlsx` 와 `견적서_template_Lenovo.xlsx` 가 EXE 옆에
자동으로 만들어진다. IBM 문서인지 레노버 x86 문서인지에 따라 변환에 쓰는
파일이 자동으로 갈리므로, 두 파일 다 Excel 로 열어 고친다.

| 고칠 것 | 위치 |
|---|---|
| 견적서 번호 `NO : Trialinfo-YY-` | TOTAL 시트 B2 셀 |
| `담당 : 시스템사업부 ○ ○ ○` | TOTAL 시트 상단 머리말 도형 |

견적서 번호는 **연도 두 자리만 자동 갱신**된다. 결과는 언제나 `NO : Trialinfo-26-`
형태이고 연도 뒤에는 아무것도 붙지 않는다.
담당자 이름은 도형 안에 있어 프로그램이 건드리지 않는다.

> 템플릿을 고친 뒤에는 저장만 하면 된다. 다음 변환부터 바로 반영된다.

### Excel 을 켜 둔 채 변환해도 된다
원본은 변환 전에 Excel 을 모두 종료해야 했다. 이제 그럴 필요가 없다.
Excel 을 쓰지 않고 화일을 직접 만들기 때문이다.

단, **변환하려는 견적서 화일 자체가 열려 있으면** 덮어쓸 수 없다.
이때는 그 화일만 닫으면 된다.

## 3. 설치와 제거

### 새 버전 설치
`QuotationTool.exe` 를 원하는 폴더에 두면 끝이다. 관리자 권한도, OCX 등록도 필요 없다.
Excel 이 없는 PC 에서도 동작한다.

### 구버전 제거
`제어판 → 프로그램 추가/제거` 에서 `견적서 자동화 프로그램` 을 제거한다.
새 버전과 함께 두어도 서로 간섭하지 않으므로, 한동안 병행 운영하다가 제거해도 된다.

## 4. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| `화일을 저장하지 못했습니다` | 같은 이름의 견적서가 Excel 에 열려 있는지 |
| `CFXML을 찾을수 없습니다` | eConfig Export 로 받은 XML 이 맞는지 |
| `견적서 작성을 위한 Item을 찾을 수 없습니다` | XML 에 품목이 들어 있는지 |

## 5. 없어진 기능

- **유지정비료(H·I열)**: 채우지 않는다. H열은 빈 칸으로 남는다.
- **할인율**: 기능 자체를 없앴다. `공급가` 행은 언제나 공란이며 수기로 적는다.
- **저장 폴더 선택**: 견적서는 언제나 XML 과 같은 폴더에 저장된다.
