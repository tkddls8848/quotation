견적서 작성기

eConfig Export XML 을 견적서 Excel 화일로 바꿉니다. 여러 개를 한 번에 고를 수 있고, XML 하나마다 .xlsx 하나를 같은 이름으로 내려받습니다.

변환 모드
XML 화일을 끌어다 놓거나 눌러서 고르십시오 확장자 .xml, 한 개당 최대 10 MiB, 한 번에 50 개까지

    요청 ID: 문의할 때 이 번호를 알려 주십시오.

    변환은 이 브라우저 안에서 이루어집니다. 고른 XML 과 만들어진 견적서는 서버로 보내지 않으며 어디에도 저장되지 않습니다. 처음 한 번만 변환기를 내려받고 그 뒤로는 다시 받지 않습니다.
