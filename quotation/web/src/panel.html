견적서 작성기

eConfig Export XML 을 견적서 Excel 화일로 바꿉니다. 여러 개를 한 번에 고를 수 있고, XML 하나마다 .xlsx 하나를 같은 이름으로 내려받습니다. IBM 제품과 Lenovo 제품(x86, ThinkSystem) XML 을 가리지 않고 알아서 구분해 변환합니다.

    변환은 이 브라우저 안에서 이루어집니다. 고른 XML 과 만들어진 견적서는 서버로 보내지 않으며 어디에도 저장되지 않습니다. 처음 한 번만 변환기를 내려받고 그 뒤로는 다시 받지 않습니다.
